# VM接続の検証用コード

セットアップは[リポジトリのREADME](../README.md)にまとめています。
VMでサーバーを設定してから、PCでクライアントを実行してください。

- `server.py`：`127.0.0.1:8788/probe/echo`でnonceを返すサーバー。
- `client.py`：VMトークンを取得し、SDKのNoise接続経由でnonceの往復を確認するクライアント。

クライアントには既存のaccess/device token、またはSDKの`pairing.json`が必要です。
トークン更新は行いません。期限切れの場合は既存SDKで認証情報を更新してください。
複数VMから選ぶ場合は`--vm-id`、転送先パスを変える場合は`--path`を指定します。
標準と異なるNoiseホストを使う場合だけ、確認した宛先を`--noise-host`で明示します。

アカウントAPIは`https://api.muse.ai`限定です。HTTP・WebSocketのリダイレクトを追わず、
TLS検証を有効にし、非表示入力が使えなければ中止します。端末登録は行いません。

サーバー単体の応答と、Museの認証済み経路からの疎通は別の確認です。
404だけでは、指定パスにルートがないことしか分かりません。
