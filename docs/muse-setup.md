# Muse VMのセットアップ

[README](../README.md)の設定用プロンプトと起動手順に従ってください。
セットアップするのは `muse-realtime-bridge` の1サーバーだけです。

同じ `127.0.0.1:8787` でecho疎通確認と `/realtime` の音声中継を提供します。
以前の `probe/server.py` は統合・削除しました。別サーバーを起動しないでください。
OpenAI認証値が未設定でもechoは利用でき、音声接続だけ503を返します。

OpenAI実キーはMuseの認証情報ストアへ登録し、代替トークンとSentinelが利用できるか
確認してください。利用できなければ実キーをチャットや.envへ保存せず報告してください。
今回のloopback構成では独自トークンの生成・外部ポート公開は不要です。
